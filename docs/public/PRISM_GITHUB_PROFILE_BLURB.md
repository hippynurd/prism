# GitHub Profile Blurb Draft

I build practical infrastructure under real-world constraints: Linux automation,
deployment workflows, privacy-focused self-hosting, old hardware reuse, and
local AI that explains the system instead of hiding it.

Current focus:

- PRISM: a local-first home server platform for turning old office PCs and
  gaming computers into private infrastructure guided by Iris
- MotherShip: factory/PXE/control workflows for building and deploying machines
- AutoCloner: practical cloning and rebuild automation
- kiosk work: deconstructing real-world kiosk systems into documented,
  rebuildable profiles

Themes:

- Old computers still have work to do.
- Private infrastructure should be understandable and controllable.
- Iris helps users understand their machine and safely set up services.
- AI should be a local operator, not a surveillance product.
- Good systems work under constraints: old hardware, messy networks, limited
  storage, imperfect docs, and recovery requirements.

I care about Linux, deployment, privacy, repairability, and building tools that
leave people more capable than they were before.
